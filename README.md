# YarnPrism

A simple YarnPrism Optimizer for real time processing.

- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/irenascent/YarnPrism.git`
2. `cd YarnPrism`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure YarnPrism, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
